# ~/.agent-socket

Settings for agent-socket tools on this machine ([agent-socket](https://github.com/blitzdotdev/agent-socket): links that let an AI chat use an app). One folder per tool:

- `gpu-browser/` — `npx @agent-socket/gpu-browser`, a GPU browser an agent can render in. See its README.

Deleting this folder removes only these settings, not the tools.
