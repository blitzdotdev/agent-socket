# Home of agent-socket-gpu-browser

The home folder of the `agent-socket-gpu-browser` account, which runs the agent-socket GPU browser (see `../README.md`). While the browser runs, Chromium keeps its temporary profile in `tmp/` here; it is emptied on every start. Nothing here is needed between runs.

Remove the whole install: `sudo sh /opt/agent-socket-gpu-browser/uninstall.sh`.
