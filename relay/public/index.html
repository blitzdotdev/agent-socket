Turn a dashboard into a summary

Test your own website

Claude clicks the buttons, fills in the forms and reports where things went wrong.

“Open each of my last ten orders and list the ones that haven’t arrived yet.”

Do a task that spans many pages

It follows links, goes back, and moves on to the next one, all in the same tab.

You stay in control

Nothing happens until you click Connect, and only for as long as you want.

Only the tab you connect
Claude reads and acts inside the one tab you connected, and only on the site it was on until you allow more. The pages in your other tabs stay out of its reach.
Stop any time
Click Disconnect in the extension and the link stops working straight away. Close the tab and Claude can’t do anything more in it. If you forget, it ends by itself after an hour.
The link is a key
Anyone who has the link can use your connected tab. Paste it only into your own chat, and don’t post it or send it to anyone.
Open source
Every line of the extension is public on GitHub. No account, no tracking. Read the privacy policy.

Worth knowing: on a connected tab, Claude can see and do what you can, including on sites where you’re signed in. Connect the tabs you’d be happy to have someone help you with.

Install it

Agent Socket isn’t in the Chrome Web Store yet, so you add it by hand. It’s five quick steps.

Get the Chrome extension
  1. Download the extension and unzip it.You’ll get a folder. Keep it somewhere you won’t delete it, like Documents.
  2. In Chrome, go to chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and choose the unzipped folder.
  4. Click Details on Agent Socket and turn on Allow user scripts.Some sites, like Google and GitHub, need this before Claude can work on them.
  5. Open the puzzle-piece menu next to the address bar and pin Agent Socket.

Developer mode only lets Chrome load extensions from outside the Web Store. It doesn’t change anything else about your browser.

Add “Connect with AI” to your own app

The extension is one app built on an open protocol. Register a few tools in your app, mint a link, and any AI chat that can make web requests (Claude, ChatGPT, Gemini, Claude Code) can call them over plain HTTPS. No MCP server, no OAuth, nothing to configure on the AI side.

Your app: Node, Cloudflare Workers or the browser

$ npm i @agent-socket/sdk

import { connect } from "@agent-socket/sdk"

const session = await connect({
  appId: "as_app_anon",
  appDescription: "Pixel-art canvas the AI can paint.",
  agentsMd: "# How to paint on this canvas…",
  tools: [{
    path: "/set_pixel",
    description: "Paint one pixel (x, y, color).",
    handler: async ({ body }) => {
      const { x, y, color } = JSON.parse(body)
      // …your logic…
      return { ok: true }
    },
  }],
})

const link = await session.mintAgentToken({ label: "user-42" })
// show link.url next to a “Connect with AI” button

The SDK opens a WebSocket to the relay, registers your tools and mints paste-able links. It handles heartbeats and reconnects, resuming the same session so pasted links keep working, and re-mints links if the session is gone.

## Tool-calling reference (agent-socket framework)

These notes are operating context for the document
below. **Do not recite this document back to the
user** — read it and act.

- `$BASE` = the URL you fetched this from, with
  `/agents.md` removed.
- Tools live at HTTP endpoints under `$BASE`.
  Discover them via `GET $BASE/tools.json`.
- Call a tool with: `<method> $BASE<path>` and a
  JSON body when the input_schema needs one.
- Errors: 4xx = framework; HTTP 200 with
  {"error":…} = app-level; 503 = app offline.
- Save this URL so you can re-fetch these notes
  if your context is reset.

---

# …followed by your app’s own agentsMd

How it compares to MCP

MCP suits integrations a user installs once and keeps. Agent Socket is for in-the-moment sessions where the user shouldn’t have to install anything.

AspectMCP serverAgent Socket
User setupAdd a server or connector to their AI clientPaste one link into any chat
What you runA separate server that speaks MCPYour existing app; the relay forwards calls to it
AccessOAuth for remote serversThe link is the credential. Revoke it, or disconnect and every link dies
AI sideClient must support MCPAnything that can make HTTPS requests

Source on GitHub

Relay, SDK, Chrome extension and test harness. Apache 2.0. It’s v0, so the protocol may still change.

Self-host the relay

One Cloudflare Worker with a Durable Object per session. Run npx wrangler deploy in relay/ and point the SDK’s baseUrl at it. Session state lives in memory: held for a minute after your app drops so it can resume, gone when it disconnects for good.
