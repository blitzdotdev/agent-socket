Most ways of letting an AI use your software tie you to one vendor or one machine. Agent Socket is a relay with one idea: your tab or app keeps an open line to it, and you give the agent a URL. Everything the agent does is an ordinary web request to that URL, answered by your tab or app as it happens.

What's different

01
  • It's a link, not a plugin. Anything that can send an HTTPS request can use it: Claude Code on your laptop or in a cloud session, Codex, Cursor, a twenty-line script. An agent running in the cloud can work in the browser on your laptop, signed in as you. Browser helpers built into one AI product work with that product, on that computer.
  • Any web app can offer it. About ten lines of the SDK turn your app's actions into URLs an agent can call. There's no MCP server to host, no OAuth to set up and no backend of your own: the page itself answers. The Chrome extension is one app built this way.
  • A link that holds. If your laptop sleeps, the Wi-Fi drops or Chrome restarts the extension, the relay keeps the session for up to 24 hours and the agent is told to retry. When your side comes back, the same link works again; you don't paste a new one.
  • Skills agents share. A public registry of site profiles: notes and ready-made tools for a site, like reading Google Sheets' canvas grid. When you connect a tab, its site's profile loads, so the next agent doesn't spend ten minutes working the site out again. New profiles are reviewed before they're published.

How it works

02

Your side opens the line; the agent only ever makes web requests. Here is one call, from the moment your tab or app connects.

  1. Your side connects. The extension, or your app through the SDK, opens one WebSocket to the relay and lists the actions it offers. It gets back a link for this session.
  2. You give the agent the link. Paste it into the chat. The agent fetches agents.md for instructions and tools.json for the list of actions; the relay answers both itself.
  3. Every action is a web request. The agent calls an action like any URL. The relay passes it down the open line, your tab or app does it, and the answer comes straight back. A call can take up to 30 seconds; longer work replies with a task to poll.
  4. You end it. Stop, closing the tab, or session.close() in your app ends the session and every link it made stops working.

Use your browser tab

03

The Chrome extension makes any tab you choose into an app on the relay. The agent can read the page, click, type, scroll, go to other pages and take screenshots, in that tab only, signed in as you.

  1. Download the extension and unzip it.
  2. Open chrome://extensions, turn on Developer mode, click Load unpacked and pick the folder.
  3. On the extension's Details page, turn on Allow User Scripts. Without it, the agent can't run its own code on sites with a strict security policy.
  4. Open the tab you want help with, click the Agent Socket icon, then Connect this tab.
  5. Copy the link, paste it into your agent and say what you want done.

Add it to your app

04

Give your app a “Connect with AI” button. Each tool is a path, a description and a handler; the handler runs in your page (or your Node process) when the agent calls it.

index.htmlnpm i @agent-socket/sdk
import { connect } from "https://esm.sh/@agent-socket/sdk@0.1"

let count = 0
const session = await connect({
  baseUrl: "https://agentsocket.dev",
  appId: "counter",
  agentsMd: "# Counter\nCall /increment to add to it.",
  tools: [{
    path: "/increment",
    description: "Add `by` (default 1). Returns the new count.",
    handler: ({ body }) => {
      count += JSON.parse(body || "{}").by ?? 1
      return { count }
    },
  }],
})
const link = await session.mintAgentToken({ label: "chat" })
// show link.url to the user: that is what they paste into the agent

The agent reads the link's agents.md, fetches tools.json, then sends POST …/increment with {"by": 2} and gets {"count": 2} back. The same app runs in Node. The limits are generous for this kind of work:

LimitValue
One call30 s; longer work replies with a task the agent polls
Request from the agent1 MiB
Reply from your appAbout 4 MiB (keep screenshots under about 3 MiB)
Calls at once100 per session
Links50 per session, each revocable on its own
Offline hold24 h, then the session ends

The full protocol, every limit and the threat model are in docs/protocol.md; the API in sdk/README.md.

    Questions

    09
    How is this different from MCP?

    MCP is a protocol an AI client has to support, and the server usually has to be hosted and set up with OAuth. Agent Socket needs nothing from the client but web requests: the link is the whole setup. The tools are the same idea (a name, a description, an input schema), so moving between the two is easy.

    How is this different from Claude in Chrome?

    Claude in Chrome lets Claude act in your browser. Agent Socket gives you a link that any agent can call, including ones that run somewhere else, like a cloud coding session; and the same relay works for your own apps, not only the browser.

    Does it work with ChatGPT or Gemini?

    It works with any agent that can send HTTP requests to a URL, including POST with a JSON body. Chat apps that can only open web pages can read the instructions but can't call the tools.

    Is it safe?

    The link is the key: anyone holding it can call the tools until the session ends, so share it only with the agent you mean to. The extension limits an agent to the one tab you connected and, by default, the site it was on; sessions stop after 60 minutes unless you change that; every action is logged on your computer for 7 days; and Stop ends everything at once. The relay doesn't keep what passes through it.

    What does the relay keep?

    While a session lasts, its setup: the tool list, the instructions, a hash of each link and results of long-running calls until they're fetched. Ending a session deletes it at once; a session left offline is deleted after 24 hours. Calls and replies are not stored. Details in the privacy policy.

    Can I run my own relay?

    Yes. It's one Cloudflare Worker: npx wrangler deploy from the repo puts it on your account, and the SDK's baseUrl or the extension's Settings point at it. See docs/self-hosting.md.

    What does it cost?

    Nothing. The code is open source under Apache 2.0, and the hosted relay at agentsocket.dev is free to use.

    Install

    10
    The Chrome extension
    1. Download the latest release and unzip it.
    2. chrome://extensions → Developer mode → Load unpacked → pick the folder.
    3. Details → Allow User Scripts.
