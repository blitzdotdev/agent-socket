# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Short version

Be respectful. Assume good intent. Disagree with ideas, not people. Don't harass anyone. Don't post things you wouldn't want screenshotted.

## Reporting

If you witness or experience behavior that violates this code, please email the maintainers at the contact listed on the [teenybase GitHub org](https://github.com/teenybase) page. Reports will be reviewed promptly and handled with discretion.

## Scope

This applies to all project spaces — GitHub issues, PRs, code comments, social-media discussion that references the project, and any in-person interactions where the project is the context.

## Enforcement

Maintainers may at their discretion remove comments, close PRs, or block accounts for violations. Severe or repeated violations may result in a permanent ban from project spaces.
